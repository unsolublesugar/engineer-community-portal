# 03. ページ設計

## デザイン基盤

- プライマリカラー: `#1668dc` 系
- フォント: IBM Plex Sans JP（日本語フォールバックに Noto Sans JP）
- ボタン・バッジ・フィルター・検索ボックス: ピル形状（`border-radius: 99px`）
- セクション見出し: `.section-title`（左端に青のアクセントバー）、件数は `.count-pill` で併記
- 日付表記: サイト全体で `YYYY-MM-DD`（イベント詳細ヘッダーのみ `YYYY-MM-DD（曜）`）
  - Jinja2 フィルター: `date_iso` / `date_iso_full` / `date_parts`（日付タイル用に年月日・曜日へ分解）

## 共通レイアウト

- ヘッダー: サイトロゴ + ナビゲーション（イベント / 登壇者 / 企画 / About）+ 「参加する」ボタン（PC）
- メインコンテンツ: ページ固有
- フッター: 「コミュニティ」「チャンネル登録」ボタン + コピーライト
- OGP / Twitter Card メタタグ対応

### モバイル対応

- ヘッダー: 「参加する」ボタン非表示（トップページのヒーローセクションに配置）。小画面（440px 以下）でもナビが横溢れしないよう調整
- フッター: コピーライト中央寄せ

## 1. トップページ（/）

- ヒーローセクション:
  - コミュニティ名 + キャッチコピー
  - 統計カード（開催スケジュール / イベント開催数 / LT発表数）: アイコンタイル + 数値 + 単位
  - モバイル: 開催スケジュールのみ表示。「参加する」ボタンは次回開催バナーと導線が重複するため、**開催予定イベントがない期間のみ**表示
- 次回開催バナー:
  - 開催予定イベントのうち最も近い1件を、イベント一覧グリッドの外・上部に横長で配置
  - 左に日付タイル（月 / 日 / 曜日 + 開始時刻）、中央にタイトルと発表プレビュー、右に CTA
  - 開始時刻は `community.yaml` の `schedule` から `HH:MM` を自動抽出
  - `event_url` があれば「参加登録する」で外部イベントページへ、なければ「詳細を見る」でイベント詳細へ
  - バナーに出したイベントはグリッドから除外
- イベント一覧:
  - カード形式、新着順
  - カード内容: イベント番号、タイトル、開催日、発表プレビュー（淡青ボックス）、発表数
  - 開催予定イベントは青背景・左ボーダー・「開催予定」バッジ付き
  - デフォルト表示: 現在年のイベントのみ
  - 年度フィルター（セグメンテッドコントロール、「すべて」を末尾に配置）
  - 「すべて」選択時: 12件ずつの「さらに読み込む」ページネーション
  - 年フィルター選択時: 下部に前年・翌年ナビゲーションボタン（両サイド配置）

## 2. イベント詳細ページ（/events/NNN）

- パンくずリスト（イベント一覧 → 当該イベント）
- イベントヘッダーカード: タイトル、開催日ピル、イベントページリンクピル（`event_url` から connpass / Doorkeeper / Peatix / TECH PLAY / Meetup を自動判定してラベル切替）、レポート記事リンクピル（`report_url` がある場合）
- YouTube動画:
  - サムネイル表示、クリックでiframe埋め込み再生（autoplay）
  - ローカル（file://）ではYouTubeページへのリンク動作（プログレッシブエンハンスメント）
- 発表一覧（見出しに件数ピル）:
  - 登壇者情報（アイコン、名前、SNSはテキストリンク）
  - 発表タイトル
  - タグ表示
  - リソースリンクは色付きピルで横並び（動画=赤系 / 記事=緑系 / スライド=amber系）
  - スライド埋め込みはリソースピルの下に配置
- ページ下部ナビゲーション: 左に前イベント、中央にイベント一覧、右に次イベント

## 3. 登壇者一覧ページ（/speakers）

- 見出しに登壇者数ピル
- 検索ボックス（ピル型。名前、ID、X、GitHub、発表タイトルで検索可能）
- ソート切替（登壇回数順 / 最新イベント順 / 名前順）
- 登壇者カード:
  - アイコン、名前、SNSはテキストリンク、登壇回数
  - 発表履歴: 淡青ボックス内のリスト（`#番号 → タイトル → 日付` の順）。最新3件を表示、4件以上は折りたたみ（展開/閉じるトグル）
- 20件ずつの「さらに読み込む」ページネーション（検索・ソートと連動）

## 4. 企画コーナーページ（/challenge）

- ページ見出し + リード文
- 2セクション構成:
  - 💪 チャレンジコーナー: `speaker.id == "easy2"` かつタイトルに「チャレンジコーナー」を含む発表
  - 🔍 ちょこっと深堀り！: `speaker.id == "easy2"` かつ上記以外の発表
- 各セクションにリード文（コーナー説明）
- カードグリッド形式: イベント番号、開催日、タイトル、動画タイムスタンプリンク
- カードクリックでイベント詳細ページへ

## 5. コミュニティ概要ページ（/about）

- 各セクションを白カード化し、見出しに青のアクセントバーを付与
- コミュニティ紹介文（スライド埋め込みも可）
- 統計情報（イベント回数、LT発表数、登壇者数、コミュニティメンバー数）
- 運営メンバー（アイコン、名前、役割、SNSはテキストリンク）
- 参加方法（コミュニティページ / YouTubeアーカイブ）
- 関連リンク

## 埋め込み対応

- **YouTube**: サムネイル + クリックでiframe埋め込み再生（youtube-nocookie.com、autoplay）
- **スライド**: iframe埋め込み（Speaker Deck, Google Slides, Docswell等、自動URL生成）
- **記事**: リンク形式で表示
